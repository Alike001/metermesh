# MeterMesh submission narration

## 00:00 to 00:16

AI work increasingly arrives through private messages. But a message alone cannot prove what was requested, what the agent delivered, or which chain facts it used. MeterMesh turns that exchange into independently verifiable evidence on X Layer.

## 00:16 to 00:40

The buyer signs one exact request and one X Layer transaction reference, then sends it through XMTP. Deterministic code reads the receipt. AI explains the result, but it cannot change chain facts, authorize payment, or decide acceptance. The seller signs the delivery, binding every output back to the request.

## 00:40 to 01:04

The browser re-verifies both signatures, the evidence hash, and the AI result binding before displaying the proof. MeterMesh also anchors that stable hash in its own contract on X Layer Testnet, chain 1952. Anyone can inspect the transaction, export the signed receipt, and verify the same evidence outside our interface.

## 01:04 to 01:30

Failure stays honest too. This real reverted transaction contains no logs and no verified reason, so MeterMesh reports exactly that instead of inventing an explanation. The same evidence is available through machine-readable documentation for other agents and builders. MPP settlement remains gated until official Testnet support is confirmed. MeterMesh makes AI work accountable, portable, and ready for the X Layer ecosystem.
